## 审查发现及修复

| 问题 | 修复与回归证据 |
| --- | --- |
| 重新加载配置期间仍能编辑/保存，旧 GET 可覆盖新修改 | 在对应 GET 期间锁定表单、保存、恢复和密钥操作；个人/管理员延迟响应浏览器测试先失败、修复后通过 |
| 模型密钥不可解密时，非模型接口也失败 | 将运行策略与模型密钥解密分离；模拟账户等非模型操作仍可用，诊断显示密钥错误；API 测试先得到 503，修复后为 200 |
| 保存个人设置会覆盖已有委托草稿类型 | 仅在空委托表单应用默认类型，保留已有股票/数量/委托类型；前端回归测试通过 |
| 退出账号后模拟开户默认值留在组件内部 | 同时清除组件内部偏好和委托类型；账号重置测试通过 |
| 返回首页后重新进入，默认页覆盖原页面 | 仅在本次登录首次进入时应用默认页；已有 19 项账号 UI 测试通过 |
| 同时创建两个账户可突破管理员配置的上限 | 同一所有者先取得 PostgreSQL 行锁再计数/创建；独立测试库并发测试由 `[201, 201]` 修复为 `[201, 409]` |
| 同一账号降为普通用户后页面仍保留管理员视图 | 监听会话权限变化，立即清空高级配置和草稿，切回个人分类；浏览器回归测试通过 |

独立审查覆盖角色/CSRF、密钥不回传、事务与版本控制、账号切换及运行时配置接入。审查指出的重新加载覆盖问题已修复；账户上限并发风险也已复现并修复。
