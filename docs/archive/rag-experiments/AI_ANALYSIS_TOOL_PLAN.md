### Day 3-4：AI风险识别引擎

**功能：**
根据知识库规则，自动识别以下风险：

1. **财务造假风险**
   - 应收账款占营收>40%
   - 现金流含金量<0.8
   - 存货周转天数延长>30%

2. **偿债风险**
   - 资产负债率>70%
   - 流动比率<1
   - 现金短债比<1

3. **盈利质量风险**
   - 毛利率异常
   - 费用率异常
   - 营业外收入占比高

**技术方案：**
```python
class RiskAnalyzer:
    def __init__(self):
        self.rag = get_rag_system()
        self.rules = self._load_risk_rules()
    
    def analyze(self, financial_data):
        risks = []
        
        # 规则1：应收账款风险
        if financial_data['receivable_ratio'] > 0.4:
            # 从知识库查询相关案例
            context = self.rag.search('应收账款占营收40%以上风险')
            
            risks.append({
                'type': '应收账款异常',
                'level': 'high',
                'indicator': financial_data['receivable_ratio'],
                'benchmark': 0.3,
                'explanation': context,
                'cases': ['万福生科', '保千里']
            })
        
        return risks
```

**交付物：**
- `app/analysis/risk_analyzer.py`
- 10-15个核心风险检测规则

### Day 5-7：报告生成

**功能：**
生成结构化的分析报告

**报告结构：**
```
1. 财务概览
   - 关键指标：ROE、PE、负债率、现金流含金量
   - 三年趋势图

2. 风险识别（重点）
   ⚠️ 高风险（3个）
   ⚠️ 中风险（5个）
   ℹ️ 低风险（2个）

3. 详细分析
   每个风险点：
   - 具体数值
   - 行业对比
   - 历史案例
   - 建议关注

4. 投资建议
   - 综合评分
   - 建议操作
```

**技术方案：**

```python
def generate_report(financial_data, risks):
```

## 技术架构调整

```

```

