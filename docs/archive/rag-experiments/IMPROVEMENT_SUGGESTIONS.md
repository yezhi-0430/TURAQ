**当前状态：** 爬虫能获取数据，但没有自动添加到RAG

**改进方案：**
```python
# 在scheduler.py中添加
async def crawl_and_store():
    crawler = EastmoneyCrawler()
    rag = get_rag_system()
    
    # 爬取数据
    data = await crawler.get_stock_info('600519')
    
    # 添加到RAG
    if data:
        rag.add_text(
            text=data['content'],
            metadata={'type': 'stock_data', 'date': today}
        )
```

**收益：** 系统真正自动运行
