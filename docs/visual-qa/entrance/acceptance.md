# K 线入场页验收 — 2026-10-12

范围仅为替换首页及登录后的平滑进入，不修改后端、账号权限、行情或模型。

## 行为与视觉

- 24 根装饰性 SVG K 线从左到右生长，最后一根约 3.48 秒完成，Logo 从 3.7 秒开始渐显，约 4.95 秒完成。背景随后降低亮度，以保证标记可读。
- 实际浏览器确认首次生成阶段 Logo 透明、只有前方 K 线出现；完成后 Logo 可见，账号窗口关闭、工作台仍隐藏，不会自动跳转。
- 动画开始后立即点击右上角登录也能打开账号窗口。中央整个画面是可聚焦按钮，点击进入登录，即使已存在有效会话也不会绕过这个入口直接跳入主页面。
- 使用隔离合成账号登录成功，账号窗口关闭，工作台与首页交叉淡入淡出。代码将窗口退场设为 200ms，入场页淡出 480ms，工作台淡入 640ms；最后隐藏首页。
- 390×844 手机页面与登录窗口均可见、无横向内容溢出。减少动态偏好对应静态入口及无动画切换，自动测试覆盖。
- 退出/会话清理会取消未完成的过渡，工作台不得因迟到的动画完成回调重新出现；两个不同阶段的取消由测试覆盖。

## 验证

过渡测试最初 4 项因缺少控制器失败，实施后通过；补充工作台已开始淡入时退出、账号仍有效时返回首页的取消回归。过渡期间鼠标和键盘再次进入的检查也先失败，增加原生 inert 保护后通过。最终 `npm run build --prefix frontend` 成功，19 模块；`node --test tests/frontend/*.test.mjs` 为 37 通过、0 失败。

独立审查指出返回首页会重播及顶部点击区域被遮挡；定格完成状态、顶部穿透后，复审确认两项已解决。复审新增的登录按钮过渡中再次触发问题由主代理补上 `.intro-leaving` 禁止点击及原生 inert 保护，经过上述回归测试和实际浏览器登录复测处理。浏览器最终捕捉到进入中 inert 生效；完成后可正常返回首页，Logo 立即保持 opacity=1、工作台隐藏、账号窗口关闭。没有未修复的本次入场功能审查项。

浏览器为独立前端 3001、后端 8891，后端仅为内存 SQLite、合成身份与确定性假模型，关闭调度器与行情网络。没有输入用户密码、访问日常数据库、调用真实模型或发信。

## 实施选择

按用户明确的效果要求及“登录后平滑进入”的追加要求直接实施；采用现有 TURAQ 标记，不复制参考图其他品牌。动画为原生 SVG/CSS 和 Web Animations，不增加动画依赖。时长是可调默认值，减少动态偏好优先。旧工作台与侧栏平滑切换保留，旧营销首页被替换。只提交本次前端与文档，保留其他已有未提交文件。
