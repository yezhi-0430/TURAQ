# 模型输出额度（2026-10-14）

研究助手与风险摘要按已确认的方案分别配置：

| 配置 | 默认值 | 适用入口 |
| --- | --- | --- |
| AGENT_MAX_OUTPUT_TOKENS | 4096 | 研究助手每轮模型回复，包括工具选择轮 |
| RISK_MAX_OUTPUT_TOKENS | 1024 | 手动资料摘要和旧版自动摘要 |
| RISK_DOCUMENT_OUTPUT_TOKENS | 4096 | 全文分批阅读、发现合并及最终综合结论 |
| MODEL_MAX_OUTPUT_TOKENS | 1024 | 未指定用途的模型调用，兼容原配置 |

四项均允许1至8192。修改环境配置后重启后端。额度是输出上限，不是固定回答长度，也不是整段对话的总额度。研究助手与风险摘要使用独立请求副本，避免共享客户端串用额度。

沿用原模型开关、用户与站点额度和并发租约。全文任务由服务端识别，独立采用 `RISK_DOCUMENT_HTTP_TIMEOUT_SECONDS=120` 和 `RISK_DOCUMENT_TOTAL_TIMEOUT_SECONDS=180`；普通助手及手动摘要继续使用原 `MODEL_*_TIMEOUT_SECONDS`。期限与数据库互斥租约一起延长，不在旧租约过期后继续请求。模型输出截断或JSON无效时保留阅读位置，不将不完整结果标成成功。

`RISK_DOCUMENT_CHUNK_CHARS=120000` 控制连续切分大小，不删除后续正文。采集不消耗模型请求次数；每个模型批次、合并和最终汇总按实际请求沿用额度。真实Qwen试读120000字、有效12条提取及12条推断，约50.5秒完成；这验证一个真实批次，不代表已经完成整组股票的模型审阅。
