❓ 邀请码是什么?
═══════════════════════════════════════════════════════════════════════════════

邀请码是由管理员生成的，用来控制谁可以注册新账号。它是一个很长的随机字符串。

🔑 如何生成邀请码?
═══════════════════════════════════════════════════════════════════════════════

方法 1: 命令行生成 (最简单)

  $ python -m app.auth.admin create-invite

  输出:
  ╭─────────────────────────────────────────────────────────────╮
  │ 邀请码 ID: 9                                                 │
  │ eHd_G8xQIs-M3hn1NgIN3eT6lN4mTOdaNZSwk5-ARaI               │
  ╰─────────────────────────────────────────────────────────────╯

👉 这个长字符串就是邀请码！把它复制下来。

⚙️ 自定义邀请码参数
═══════════════════════════════════════════════════════════════════════════════

默认: 50 人使用，有效期 7 天

增加使用次数 (100 人):
  $ python -m app.auth.admin create-invite --max-uses 100

增加有效期 (30 天):
  $ python -m app.auth.admin create-invite --days 30

两个都调整:
  $ python -m app.auth.admin create-invite --max-uses 100 --days 30

📝 使用邀请码注册
═══════════════════════════════════════════════════════════════════════════════

1. 打开应用
   → http://localhost:3000

2. 点击"注册"

3. 填写注册表单
   邮箱:      user@example.com
   密码:      password123 (6-15 字符)
   邀请码:    粘贴刚才生成的长字符串

4. 点击"提交注册"

5. 收到验证邮件，点击验证链接

6. 邮箱验证成功，账号激活！

7. 登录应用

💾 邀请码一次只显示一次
═══════════════════════════════════════════════════════════════════════════════

⚠️  非常重要！邀请码生成后只显示一次。

如果你刷新页面或关闭终端，这个邀请码就看不到了。

所以要么:
  1. 立即使用邀请码注册
  2. 或把邀请码写下来/复制到文本编辑器保存

如果丢失了:
  ✅ 生成新的邀请码: python -m app.auth.admin create-invite

🔧 管理邀请码
═══════════════════════════════════════════════════════════════════════════════

查看邀请码 ID 和信息:
  → 数据库表 invites 中查询

增加邀请码使用次数 (例如 ID 为 9):
  $ python -m app.auth.admin adjust-invite 9 --max-uses 100

延长邀请码有效期 (例如 ID 为 9):
  $ python -m app.auth.admin adjust-invite 9 --days 30

撤销邀请码 (禁用它):
  $ python -m app.auth.admin adjust-invite 9 --revoke

❌ 常见问题
═══════════════════════════════════════════════════════════════════════════════

Q: "邀请码无效或已过期"

A: 邀请码可能:
   • 已过期 (超过有效期)
   • 已用完 (达到 max_uses 限制)
   • 被撤销了
   • 拼写错误
   
   解决: 生成新邀请码

─────────────────────────────────────────────────────────────────────────────

Q: 邀请码丢失了怎么办?

A: 无法恢复。生成新邀请码:
   $ python -m app.auth.admin create-invite

─────────────────────────────────────────────────────────────────────────────

Q: 能重新显示已生成的邀请码吗?

A: 不能。邀请码只显示一次。建议生成新的。

─────────────────────────────────────────────────────────────────────────────

Q: 可以让邀请码永不过期吗?

A: 可以。设置一个很长的有效期:
   $ python -m app.auth.admin create-invite --days 365
