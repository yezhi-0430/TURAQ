# TURAQ 第三步：公开年报证据验收设计与计划

日期2026-10-23，沿用用户“下一步”授权顺序实施，无付费调用、无上传、无提交/推送，保留原未跟踪文件。本轮使用PDF只读核对、brainstorming/writing-plans、TDD及独立review。

目标：公开原始PDF与本地抽取快照；独立于生成模型的事实金标准；结构化证据评分；显式opt-in真实Qwen入口（本轮不执行）。不把预设输出的得分称为模型基线，不扩展生产交易/权限/UI。

设计：evaluations/turaq/public_reports 保存两份官方2024年报（茅台143页、平安296页）、全部逐页文本、源URL/证券/报告期/发布日期/首次本地取得时间/原始与文本hash/抽取器版本。披露只有日期，未知准确公开时刻，不伪造visible_at；as_of按日期保守过滤。gold仅评分器读取，不进入生成messages，标注单独视觉核对，非双人金融专家标注，不是未曝光held-out。

10案例：茅台2024/2023营业收入、2024归母净利润和经营现金净额；平安2024营业收入、归母净利润、不良贷款率；缺2025期间、截止日早于披露、证券不匹配三种拒答。候选须返回证券、指标期间、数值字符串、原表单位和定位到抽取文本的证据（PDF物理页码+字符start/end+原文quote）。不计算投资评级。PDF印刷页码只作显示映射，不作为定位键。

app/report_evidence_eval.py 独立于合成loop评分器，以免混用分数。模式validate仅验语料；fixture仅验证机制；score仅复核外部答案且不证明执行真实性；live须 --allow-paid-model 与环境key、明确Qwen模型，冻结公开输入只含允许文档，限制尝试数/总时间/输出上限。保存实际usage或未知，成本未知，所有请求重试计入；实验不访问业务DB或绕过生产API额度。live入口不等于已经运行，报告必须明确模式。
