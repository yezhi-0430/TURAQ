# 黑金控件与展开动效

2026-10-13：截图中的系统原生下拉菜单已替换为主题组件。适用于风险范围/股票/类型/等级/状态、分析表单、自选相关选择、管理筛选与行情复权等当前单选控件。

控件使用深色渐变、细金边、圆角、阴影、选中勾标、金色高亮与箭头转向；打开约 240ms 淡入/位移，收起约 140ms。列表有高度限制和主题滚动条，弹窗内通过浏览器 top layer 避免裁切。滚动时跟随锚点，锚点离屏即关闭；小屏自动调整左右位置和向上/向下展开。

统一点击反馈覆盖按钮和链接；按压使用独立 scale 属性以保留搜索按钮等既有定位 transform。登录、分析、确认、行情详情等 dialog 自带打开过渡，既有登录入场与页面导航动画继续使用。风险详情、搜索结果、后台子面板与邀请码内容淡入；分析历史、来源片段、工具记录等 details 支持可中断的高度/透明度展开与收起。

原生 select 保留表单取值、提交、业务 change/input 监听和验证。仅选择真正变化时触发一次业务事件。组件同步动态选项、disabled、表单 reset，以及程序对 value/selectedIndex 的直接赋值，后者不主动触发业务请求。标签文字激活主题选择器，不唤起系统原生弹层。支持方向键、Home/End、Enter/Space、Esc、Tab、输入字符定位选项，ARIA 提供标签、当前值、展开状态与选项状态。

账号退出时立即关闭所有菜单、取消动效并清除浮层内容，不延迟业务权限清理。所有选项使用 textContent。系统减少动态效果时停用新增动画和按压缩放，保留完整交互。日期输入的浏览器日历仍使用原生输入能力。

实现：frontend/theme-ui.js、frontend/theme-ui.css；index.html 引入、Vite 打包。未改变 API、后端、统计或模型功能。

验收：主题组件浏览器测试覆盖桌面/手机/减少动态效果、动态取值、表单重置、标签/键盘、长列表、弹窗、快速展开收起、详情显现及账号清理；生产构建风险页面覆盖真实导航动效、下拉、弹窗内菜单、分析与历史闭环，确认无横向溢出和浏览器异常。51 项既有前端测试与生产构建通过。独立审查工具因模型容量不足未完成，已结合浏览器回归逐项复核。
