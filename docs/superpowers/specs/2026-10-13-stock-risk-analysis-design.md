# 自动风险分析与财报阅读：框架草案

状态：用户已授权开发，已完成首版范围触发分析和文档阅读。实际实现、验证及与完整框架的差异见 [实施说明](../../automatic-risk-analysis.md)。

## 一、目标

用户选择全部自选组、指定分组或范围内某只股票，系统自动获取真实资料并分析。另提供股票名称/代码搜索，选中后可直接分析组外股票，不自动变更自选。

风险监控和AI研究助手共享行情、公告、财报获取及文档阅读能力。用户不需要先复制财报原文；手动导入仅保留为补充或数据源不可用时的备用方式。

“选择后自动分析”属于本次需求，后台定时持续扫描属于后续独立阶段。自动处理完成不意味着已核查所有公司风险，必须展示实际覆盖。

## 二、页面与触发方式

保留黑金主题、账户栏、导航、响应式及平滑交互。顶部主入口改为“自动风险分析”，包括：

- 自选范围：全部自选组或指定组。
- 指定股票：当前范围内全部股票或单只。
- 搜索股票：名称、六位代码或完整市场代码，支持组外股票；重名显示候选。
- 分析区间：默认最近90自然日，另可选30/180日，行情单次最多366日。
- 状态：已处理/总数、成功/部分失败/失败、资料覆盖、实际数据日期和生成时间。
- 操作：重新分析、停止后续处理、刷新结果；手动公告/财报分析为补充入口。

用户明确选择范围、指定股票或搜索候选后自动开始，无需再导入资料。搜索输入阶段只查候选，不在每次按键时调用模型；名称歧义不能自动选第一只。首次打开页面或恢复历史筛选不启动收费模型请求。

快速连续更改范围进行短暂防抖，合并为最终选择。重复选择同一范围复用正在执行的任务，已完成的同范围/区间结果先展示原分析时间，只有明确“重新分析”才创建新版本，避免重复消耗额度。显示将处理的股票数；额度不足明确提示已完成项和未处理项。

组内分析与外部搜索为两种明确范围：组外股票显示独立结果和当前单股统计，保留历史；不混入所选组的股票数或风险数量。切回自选范围后恢复该范围结果。

## 三、统一处理流程

范围解析与股票确认 → 真实行情/公告/财报获取 → 文档解析与证据定位 → 程序计算 → AI解读 → 保存记录 → 更新进度、事件和概览。

多股票创建持久化任务，保存服务端解析的去重证券范围快照。分批串行处理，逐股返回结果；一只失败不阻断全部。每次模型处理遵守原用户并发租约、额度和60秒期限，大组不能塞进一次60秒请求或绕过额度。

范围变化后旧任务不得覆盖当前视图；停止只取消未开始项，已完成结果继续保留。任务使用数据库领取锁与有限租约，避免多worker重复运行；重启后只恢复可确认尚未执行的项，模型结果不确定的项标记待核对，不盲目重放。

任务状态queued/running/completed/partial_failed/failed/cancelled；逐股状态pending/running/completed/partial_failed/failed/cancelled/unconfirmed。额度受限记录阻断原因及剩余未处理项，提供后续显式恢复。资料覆盖状态与任务状态、风险等级、处理状态分别管理。

## 四、AI助手的财报与文本工作能力

这些能力属于TURAQ后台的只读能力，不是安装到Codex的本地技能。风险分析流程和聊天助手使用同一服务层，聊天中依问题选择所需资料，页面只呈现答案、必要引用及适当总结。

| 能力 | 输入 | 输出与边界 |
| --- | --- | --- |
| 查找财报 | 股票、报告类型/报告期 | 实际已披露报告的标题、报告期、发布日期、稳定文档ID与来源；“最新”由检索决定，不按日历猜测 |
| 查找公告 | 股票、时间范围、资料类型 | 实际公告清单及来源；限范围和条数，不以未找到认定无风险 |
| 阅读文档 | 服务端已查到的文档ID、页码或章节 | PDF/正文中的文字、表格与出处；不接受模型任意网址，不把整本报告塞进一次请求 |
| 查找原文证据 | 文档ID、主题或问题 | 文档内相关原文片段、页码/章节与定位信息；不足时明确未找到，初期支持文档内检索，不建设完整RAG |
| 提取财务数据 | 文档ID、字段与报告期 | 营收、利润、经营现金流、资产负债等实际披露数字和原文依据，保留币种、单位、合并/母公司口径及原报告精度 |
| 对比报告期 | 已提取且可核对的同口径数据 | 程序计算同比、比率和变化；避免季度累计值与单季混用，不同期间或重述数据注明差异，缺项和零基数留空 |
| 解释报告风险 | 有证据的事实与计算 | 简要解读、推断、未知项、评级依据及引用，不输出调用过程；行业口径不适用时说明，不能套统一阈值 |

默认风险分析查找最新已披露年报、最新其他定期报告及其可比期间资料，并检索设定范围内的相关公告。超出任务文档上限时列出未覆盖资料，不冒充完整审阅。用户指定某报告时优先按指定目标处理。

PDF按页/章节解析与分段，保留原文及文件哈希。提取失败、扫描件/OCR未启用、表格定位不可靠、文档超限分别标识；未经原文对照的模型提取值只作待核实材料，不进入可信数值计算。后续OCR独立接入，不用猜测填充识别失败的数字。

文档读取设置独立可配置的大小、页数、下载/解析时间与任务数量上限，不能套用仅1MiB的现有行情预算。单次模型材料仍有界，长文按证据片段组合，不改变手动粘贴20000字限制。缓存原文与解析结果供两个页面复用。

## 五、来源和证据

候选来源优先为官方披露渠道：

- [巨潮公告查询](https://www.cninfo.com.cn/new/commonUrl/pageOfSearch?url=disclosure/list/search)：已核实页面存在公告查询和PDF阅览说明。
- [上交所上市公司公告](https://www.sse.com.cn/disclosure/listedinfo/announcement/)：已核实官方公告入口。
- [上交所经营业绩概览](https://www.sse.com.cn/disclosure/listedinfo/listedcompanies/)：页面明确其XBRL展示信息应以对应PDF为准，可作为原文核对设计依据。

核实日期：2026-10-13。上述验证仅证明公开入口存在，未证明项目已接通或具备稳定自动API；实施先验证各市场的证券匹配、列表获取、附件下载和解析，再启用对应能力。需要授权的接口必须单独配置，不能假定免费可用。

文档元数据包括document_id、provider、symbol、title、report_period、published_at、source_url、fetched_at、content_hash及解析状态。引用包括document_id、页码/章节、原文片段、定位方式和对应结论。官方来源也不等于提取字段已完全核验，原文、提取、计算与模型推断分别保存。

动态观测保留交易/报价/采集时间、复权、单位、覆盖范围；报告期、发布日期、采集时间和分析生成时间分开。更正公告关联旧版资料，新版本不可静默覆盖旧结果。用户补充材料仍为“用户提供，未核验”。

## 六、后端与数据结构

复用现有登录、apiClient、模型额度、股票目录、报价/日线/指标计算、RiskAnalysis/RiskEvent、事件详情及处理状态。新增范围任务编排、披露适配器、文档解析/检索、财务提取与同口径计算服务。

拟新增接口：

- POST /api/v1/risk/tasks：request_id、scope（all/group/stock）、group_id或已确认symbol、行情区间；服务端校验组归属并生成证券快照。
- GET /api/v1/risk/tasks/{id}：当前用户任务、逐股结果、进度和覆盖；可刷新后继续查看。
- POST /api/v1/risk/tasks/{id}/cancel：停止未执行项，不删除已保存分析。
- POST /api/v1/risk/tasks/{id}/resume：只恢复明确可重试项，重新检查用户额度；不自动重放不确定项。
- 股票搜索复用 /api/v1/stocks/search；风险历史、详情与状态更新复用既有路由，按需扩展范围参数。

新增RiskTask/RiskTaskItem保存范围、范围快照、状态、逐股错误、领取租约与分析关联；Document/DocumentExcerpt保存公共披露原文、元数据及可定位证据。公共披露缓存与用户私有分析分开，用户上传材料不能被公共缓存暴露。

分析记录增加证券代码/名称快照、输入方式、任务关联和覆盖元数据，旧文本记录兼容；事件保留关联股票ID与独立证券快照。按规范代码匹配自选，保证组外分析及以后加入自选的历史可见。保存不可变分析版本，重分析不重置既有已查看/持续关注状态。

request_id解决重传幂等；owner+symbol+资料/行情版本+规则版本解决重复事件。不能用模型文字摘要作为去重键。列表、概览采用一致用户及范围筛选，非自选单股统计与自选监控统计分开。

迁移采用备份后的显式、可重复增量升级，不覆盖工作区已有修改或原业务记录，不自动加入自选。

## 七、等级、异常与权限

风险等级高/中/低/信息不足；处理状态未查看/已查看/持续关注，互不替代。

按公告、财报、量价分别标注判断与覆盖。未接通或缺少关键资料时整体风险为信息不足，不能以行情平稳判断公司低风险。量价先展示数值与线索，未经真实样本验证的规则不产生正式等级或情绪分数。等级依据保留规则/方法版本与出处。

无匹配、名称歧义、无资料、源不可用、解析失败、样本不足、模型关闭、限流、超时和部分失败分别呈现。已有可用事实保留，全部源失败不生成成功结论。时效以真实日期展示，缺少交易日历时不按自然日认定周末行情过期。

风险任务、用户文档及结果按服务端身份隔离，跨账号读写返回404。沿用Cookie/CSRF及额度；文档来源ID只解析服务端已查到的受限公开地址，拒绝私网、凭据、任意跳转和可执行文档内容。原文中的指令不能改变权限或执行规则。

账号退出/切换清理搜索、选中股票、任务订阅和私有详情；停止轮询与展示旧请求，但不将关闭页面伪称后台任务已取消。迟到响应受账号与范围版本保护。

## 八、实施与验收

1. 验证披露源并打通真实资料读取；建立统一文档/证据结构，将财报公告阅读能力接入助手。
2. 改风险入口：自选范围自动处理、指定股票、组外搜索、批量任务、真实覆盖和逐股进度。
3. 结构化风险解读、历史持久化、去重、状态跟踪、继续研究及同口径统计；行情与文档复用已有数据。
4. 定时持续扫描、OCR和完整RAG独立后续实施；本次不创建Codex定时任务或模拟自动监控。

验收：自选全范围/分组/单股，组外搜索，歧义候选，自动触发防抖，页面打开不误触发模型，批量部分失败与额度停止，刷新恢复任务，多worker不重复，原文页码/引用可核对，财务单位/期间/更正版本，文档超限和解析失败，假模型显式标识，两账号隔离与迟到响应，现有功能回归，安全渲染，桌面/手机页面和构建测试。

本轮只更新框架并检查现有代码与公开披露入口，没有修改功能代码、数据库、模型配置或执行真实股票分析。
