# 系统设置中心

用户已批准个人/管理员分层方案，并要求功能全面，直接实施和自行审查。

## 个人设置
按账号持久化：默认页面、显示密度、减少动画；行情刷新/间隔、图表周期/复权；自选排序；研究发送快捷键/最大轮数；风险默认级别、处理状态、公告回溯天数；模拟交易刷新/间隔、新账户资金/佣金、默认委托类型。提供恢复默认、JSON 导入/导出、账号信息、修改密码、当前会话及退出其他会话。个人配置不能修改全站策略。

## 管理员设置
包含个人设置与独立全站面板：模型开关/供应商/名称、请求及输出预算、用户和全站额度、行情限流；模拟账户数量上限；服务诊断；配置导出/恢复部署默认；按时间倒序展示脱敏变更记录。模型 API 密钥以只写方式更新，数据库加密储存，缺少部署加密密钥时明确说明配置方法，不明文储存。

## 实现约束
复用当前账号、CSRF、SQLAlchemy 与暗色金色界面。新增独立设置表，不修改现有数据；当前工作区含大量未提交的已完成功能，在此基础上增量开发，不替换或提交他人改动。配置版本控制防止并发覆盖；错误明确可重试；账号切换防止旧响应回填。所有可编辑字段必须有真实消费者。密钥不出现在响应、审计或导出里。管理员接口由后端鉴权。数据库异常不得伪装保存成功。

## 验收
后端鉴权、隔离、CSRF、非法输入、版本冲突、默认恢复、运行时应用、会话撤销和密码变更测试；前端状态、导入校验、实际联动测试；构建；桌面/移动端浏览器检查；独立代码审查与问题修复。
