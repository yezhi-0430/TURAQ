# 股票行情详情

用户已指定实现范围：股票详情弹窗、分时十字线（时间、价格、涨跌幅）、均价线、成交量、日/周/月K；使用真实数据并自动更新。

点击关注行情的证券打开原生 dialog，顶部展示真实快照，默认分时，支持日K、周K、月K。共用 SVG 绘图组件，十字线吸附最近记录，成交量与价格图共享横轴；支持触摸与键盘左右查看。股票分时均价使用源累计成交额/累计股数，成交量使用累计手数差分，缺字段显示缺失，不生成价格或成交量。指数不绘制股票均价。分时昨收来自同份数据源快照；快照日期不匹配时不展示涨跌幅。

腾讯公开 minute/query 与 fqkline/get 提供真实数据。K线使用源原生 day/week/month、不复权，每次最多320根，按日期验证排序。周/月最后一根可能未结束，界面提示。K线涨跌幅以相邻周期收盘价计算；第一根无前收时显示缺失。不用实时快照替换历史K线价格。

报价10秒更新，图表30秒更新，可手动刷新/暂停。服务端缓存与失败冷却，失败保留旧数据并标记；关闭详情和隐藏页面停止请求。切换证券或周期取消旧请求，避免串数据。悬停中更新保留对应时间定位。弹窗支持Escape、关闭按钮、焦点恢复和窄屏布局。公开行情可能延迟，明确显示来源、交易日和获取时间。

测试覆盖单位、差分、均价、OHLC、非法数据、缓存故障、接口验证、弹窗生命周期、快速切换与交互；真实接口冒烟与浏览器视觉检查。
