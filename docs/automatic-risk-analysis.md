# 自动风险分析与财报阅读（2026-10-13）

## 2026-10-14 分批全文分析

新建的自动分析任务使用 `stock_overview_v3_whole_disclosure`：完整分页查询所选日期范围内的披露，定期报告查近两年，公告查所选区间；逐份提取全部可提取文字，连续分批阅读并合并发现。取消首份公告、首几页、每页6000字及自动材料20000字的节选限制。手动粘贴资料仍沿用20000字接口。

采集 `/collect` 不扣模型请求额度，每次处理一页清单或一份文件；阅读 `/process` 每次推进一个连续批次或最终汇总，保留字符位置、页序、发现和原文证据。默认每批120000字是切分大小，剩余文字继续阅读；每批4096输出token、模型HTTP120秒、总处理180秒。额度不足、格式错误或超时不会跳过未读文字，可以继续未完成项。短期限限流可自动等待，日额度耗尽则保留任务等待恢复。

任务执行是否完成与资料是否完整分开：已有真实数据可以形成趋势、量能及板块结论；清单、文件或某项数据失败另列具体原因。页面展示文件数、实际PDF页序和已阅读字数，不再笼统将完成分析标成失败。PDF文字提取不包含OCR，不等同于已验证全部表格、图片或财务指标。

缓存丢失回到提取步骤；来源内容版本变化时重启全文阅读，避免新旧页序混用；最终综合结论再次检查行情时效。模型模式变化禁止跨模式续读。历史分析保留生成时内容，旧任务不会自动改写成新规则结果。详细边界见[全文实施说明](full-disclosure-reading-plan.md)。

风险监控现在支持选择自选组、指定股票后自动处理，也可以搜索并选择组外股票。搜索输入只查询候选；选择后创建任务并逐股分析。首次打开页面不启动模型调用，默认全部范围可通过“分析当前范围”启动。手动粘贴资料仍可补充。

## 已实现

- 服务端解析当前账号自选范围、去重证券并保存快照；单股允许不在自选内，不添加或修改自选。
- 默认90自然日，可选30/180日；任务保存结束日期，恢复时行情、公告和财报查询仍使用原日期。
- 真实报价、日线、技术与量价程序统计；从巨潮公开披露源查询财报/公告并下载已查到的PDF，按页保留文字、来源与文件页序。
- 分别显示行情、财报、公告覆盖，部分失败保留已有事实。综合分析将程序事实、模型解读、未知项和原文证据分开，不把模型来源字符串视为已核验证据。
- 持久化任务进度、逐股状态与结果。处理前校验范围和状态，再申请原模型额度；每只股票服从原用户并发租约、模型开关、限流和总期限。
- 风险历史、详情、已查看/持续关注、继续研究。综合分析有独立类型，单股搜索统计与自选分组分开；研究跳转控制在4000字以内。
- 选择防抖、重复范围复用、停止未开始项、继续已确认失败/取消项、刷新进度。过期处理租约标记结果待核对，不自动重放模型请求。
- 按用户隔离任务与事件；前端账号/范围版本拒绝迟到响应，退出清理输入、搜索、任务和私有结果。

本次新增`risk_tasks`、`risk_task_items`两张表；原分析/事件表结构及用户、自选和行情数据未改。股票身份、覆盖和任务关联使用已有context及任务快照保存。

## 研究助手新增6项文档能力

目前共19个只读能力，其中包括6项文档能力和综合市场风险能力。普通对话仍直接回答，后台按问题读取资料，不展示调用过程。

报告类型与发布日期来自真实清单，不按日历猜“最新”。报告对照返回带来源的并列原文；字段提取、单位、合并/母公司、累计/单季、报告期及更正版本仍需原表核对。当前没有可靠的自动财务表格认证或同比/比率生成器，不将模型猜测数字转为程序事实。

公共文档缓存在`.local-backups/disclosures`，仅包含公开披露资料，没有用户上传内容或私有分析。稳定文档ID由证券和允许的附件路径生成，模型不能提交任意URL/文件路径。初期文档内关键词检索不等于完整RAG知识库。

## 数据与执行边界

任务由打开的风险页面串行推进。离开页面或关闭浏览器后，已经开始的股票请求仍由后端完成并保存；尚未开始的项等待用户回到页面点击“继续未完成项”。刷新会恢复任务信息，不自动追加模型请求。本轮没有后台持续worker或定时扫描，页面明确注明这一点。

当前任务最多100只股票，超限须选择更小分组；每步期限与互斥租约一致，长文档模型步骤使用上面的独立预算。行情共享原有8次HTTP/8秒/1MiB边界。披露读取每步另有8次请求、单次至多12秒、元数据2MiB、PDF20MiB/500页、解析20秒限制。PDF在隐藏子进程中解析，Windows Job Object/Unix地址空间限制为768MiB；超时终止并回收进程，内存保护设立失败则拒绝解析，不退回无界执行。

旧版直接 `/process` 的兼容路径仍保留原有限摘要逻辑；新版页面先 `/collect` 再分批 `/process`，不走该兼容路径。全文处理只覆盖任务选择的时间范围及清单中可核实的文件，不声称覆盖公司全部历史披露。

2026-10-14已改为[市场风险参考判断](market-risk-design.md)：趋势、量能、回撤及真实行业/题材/沪深300共同日期对照支持独立判断，财报与公告覆盖缺失单独说明。初版透明规则尚待回测，低市场风险不表示公司没有财务或公告风险；模型不能覆盖程序市场评级。样本不足、数据过期或复权未知仍为信息不足。旧记录保留生成时结果，点击“分析当前范围”生成新规则分析；不批量改写用户旧历史。已有手动资料摘要的独立评级逻辑保留。

重复自动选择同证券范围、区间和结束日复用任务；主动“分析当前范围”创建新的分析版本。同一用户、证券、区间长度、行情交易日（缺失时使用任务结束日）、披露文档集合及规则版本相同的结果复用事件，继承已查看/持续关注状态，事件指向最新分析。历史版本保留各自输入、结果和证据，可单独查看，不能通过历史详情修改当前处理状态。未来持续扫描的逐公告事件及规则仍需单独设计去重标识。

数据源目前接入巨潮公开披露入口，[公告查询](https://www.cninfo.com.cn/new/commonUrl/pageOfSearch?url=disclosure/list/search)。目录不包含或响应缺少某证券时明确失败，未做其他源的隐式补造；跨市场覆盖需进一步验证。OCR、自动财务表格认证、持续扫描和完整RAG未接通。
