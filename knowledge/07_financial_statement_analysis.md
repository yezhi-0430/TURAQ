## 一、资产负债表分析

### 1.1 货币资金分析

#### 概念
货币资金包括库存现金、银行存款、其他货币资金（如存出投资款、银行汇票存款、银行本票存款、信用卡存款等）。

#### 适用条件
- 适用于所有上市公司
- 特别关注现金占比高的公司

#### 检查步骤
1. **查看货币资金占总资产比例**
   - 正常范围：5%-20%
   - 过高（>30%）：可能存在资金闲置或隐藏问题
   - 过低（<5%）：流动性风险

2. **对比有息负债与货币资金**
   - 货币资金 > 有息负债：财务健康
   - 货币资金 < 有息负债：需警惕偿债能力

3. **其他货币资金占比**
   - 占比过高（>50%）：警惕受限资金
   - 检查附注中的受限情况

4. **现金流量表验证**
   - 对比"期末现金及现金等价物余额"
   - 差异应为受限资金

#### 异常线索（非违规）
- 货币资金很高，但经营现金流为负
- 货币资金很高，但大量有息负债
- 其他货币资金占比异常高

#### 已证实违规案例
**康美药业案例（财务造假）**
- 虚增货币资金299.44亿元
- 特征：货币资金巨额，但利息收入极低
- 检查方法：计算存款利息收入/货币资金，正常应在1.5%-2%

#### 出处
- 第2章 资产负债表，第23-35页
- 第11章 财务舞弊识别，第287-289页

### 1.2 应收账款分析

#### 概念
应收账款是企业因销售商品、提供劳务等经营活动应收取的款项。

#### 适用条件
- 所有采用信用销售的企业
- 特别关注B2B业务为主的公司

#### 检查步骤
1. **应收账款周转率分析**
   ```
   应收账款周转率 = 营业收入 / 平均应收账款
   应收账款周转天数 = 360 / 应收账款周转率
   ```
   - 对比行业平均水平
   - 对比公司历史数据
   - 周转天数延长需警惕

2. **应收账款占营收比例**
   ```
   应收账款/营业收入
   ```
   - 正常范围：15%-30%（因行业而异）
   - 比例上升：可能放宽信用政策或回款困难

3. **应收账款增长率 vs 营收增长率**
   - 应收账款增长率 > 营收增长率：警惕信号
   - 持续超过2年：高度警惕

4. **坏账准备计提比例**
   - 对比同行业公司
   - 计提比例偏低需警惕
   - 检查账龄结构

5. **前五大客户应收占比**
   - 占比过高（>50%）：客户集中度风险
   - 关联方应收：警惕利益输送

#### 异常线索（非违规）
- 应收账款增长快于营收增长
- 应收账款周转天数持续延长
- 坏账准备计提比例低于同行
- 大额应收账款对应关联方

**正常解释可能：**
- 行业账期延长（如工程类）
- 拓展大客户，给予更长账期
- 季节性因素（四季度销售集中）

#### 已证实违规案例
**东方海洋案例（虚增收入）**
- 通过关联方虚构销售
- 应收账款长期挂账不回收
- 特征：应收账款/营收比例异常高（>50%）
- 出处：第289-291页

**獐子岛案例**
- 应收账款周转天数从30天延长至180天
- 实际为销售不畅，虚增收入
- 出处：第292-293页

#### 出处
- 第2章 资产负债表，第35-48页
- 第11章 财务舞弊识别，第289-293页

### 1.3 存货分析

#### 概念
存货包括原材料、在产品、半成品、产成品、商品等。

#### 适用条件
- 制造业、零售业等有实物存货的企业
- 不适用于服务业、金融业

#### 检查步骤
1. **存货周转率分析**
   ```
   存货周转率 = 营业成本 / 平均存货
   存货周转天数 = 360 / 存货周转率
   ```
   - 对比行业平均
   - 周转天数延长警惕滞销

2. **存货占总资产比例**
   - 制造业正常范围：15%-30%
   - 比例过高：资金占用大，跌价风险

3. **存货跌价准备**
   - 计提比例对比同行
   - 账龄超过1年的存货关注

4. **存货结构分析**
   - 产成品占比高：可能销售不畅
   - 在产品占比高：生产周期长或积压

5. **存货与收入/成本匹配**
   - 存货增长 > 收入增长：警惕
   - 存货+应收增长远超收入：高度警惕

#### 异常线索（非违规）
- 存货周转天数持续延长
- 存货增速远超营收增速
- 存货跌价准备计提不足
- 产成品占比异常高

**正常解释：**
- 备货旺季（如空调夏季前）
- 原材料价格低位囤货
- 新产品上市前备货
- 项目制生产（如造船）

#### 已证实违规案例
**蓝田股份案例（虚增存货）**
- 虚构存货数量
- 特征：存货占比异常高（>60%），但周转率低
- 出处：第295-296页

**獐子岛案例**
- 虚增海洋牧场存货
- 后以"自然灾害"为由核销
- 出处：第296-298页

#### 出处
- 第2章 资产负债表，第48-62页
- 第11章 财务舞弊识别，第295-298页

## 二、利润表分析

### 2.1 营业收入分析

#### 概念
营业收入是企业在销售商品、提供劳务等日常经营活动中形成的收入总额。

#### 适用条件
- 所有企业

#### 检查步骤
1. **收入增长率分析**
   ```
   收入增长率 = (本期收入 - 上期收入) / 上期收入
   ```
   - 对比行业增速
   - 对比公司历史增速
   - 突然加速或减速需关注原因

2. **收入季节性分析**
   - 查看单季度收入占比
   - 第四季度占比过高（>40%）警惕突击确认收入

3. **收入结构分析**
   - 主营业务收入占比
   - 新业务占比变化
   - 地区收入结构

4. **收入质量分析**
   - 结合应收账款分析
   - 结合经营现金流分析
   - 现金收入比 = 销售商品收到的现金 / 营业收入
   - 正常应≥100%

5. **关联交易收入**
   - 关联方收入占比
   - 占比过高（>30%）警惕利益输送

#### 异常线索（非违规）
- 第四季度收入占比异常高
- 收入增长但现金流为负
- 关联方收入占比高
- 收入突然大幅增长但没有合理解释

**正常解释：**
- 季节性行业（如空调、取暖设备）
- 项目制确认（如工程、软件）
- 新产品上市
- 行业高景气

#### 已证实违规案例
**万福生科案例（虚增收入）**
- 虚构销售合同和发货单
- 特征：收入大增但现金流为负，应收账款激增
- 计算：现金收入比<60%，应收账款/营收>50%
- 出处：第301-303页

**欣泰电气案例**
- 提前确认收入
- 四季度收入占比超过60%
- 出处：第303-304页

#### 出处
- 第3章 利润表，第63-78页
- 第11章 财务舞弊识别，第301-304页

### 2.2 营业成本与毛利率分析

#### 概念
- 营业成本：与营业收入直接相关的成本
- 毛利率 = (营业收入 - 营业成本) / 营业收入

#### 适用条件
- 所有企业

#### 检查步骤
1. **毛利率水平分析**
   - 对比行业平均毛利率
   - 对比公司历史毛利率
   - 显著偏离需合理解释

2. **毛利率趋势分析**
   - 持续上升：产品提价或成本下降
   - 持续下降：竞争加剧或成本上升
   - 突然大幅变化需警惕

3. **产品毛利率结构**
   - 不同产品线毛利率
   - 高毛利产品占比变化

4. **成本构成分析**
   - 原材料、人工、制造费用占比
   - 成本结构变化合理性

5. **毛利率与行业对比**
   - 显著高于行业（>20%）：警惕或优势
   - 显著低于行业：竞争力弱

#### 异常线索（非违规）
- 毛利率显著高于同行
- 毛利率持续下降
- 毛利率突然大幅上升
- 成本构成异常变化

**正常解释：**
- 技术领先，产品定价高
- 规模效应，成本下降
- 原材料价格下降
- 产品结构升级

#### 已证实违规案例
**绿大地案例（虚增毛利率）**
- 虚减营业成本
- 毛利率从行业平均30%虚增至60%
- 出处：第306-307页

#### 出处
- 第3章 利润表，第78-92页
- 第11章 财务舞弊识别，第306-307页

## 三、现金流量表分析

### 3.1 经营活动现金流分析

#### 概念
经营活动现金流净额是企业日常经营活动产生的现金净流入。

#### 适用条件
- 所有企业

#### 检查步骤
1. **经营现金流与净利润对比**
   ```
   现金流含金量 = 经营活动现金流净额 / 净利润
   ```
   - >1：优秀，盈利质量高
   - 0.8-1：良好
   - <0.8：警惕，盈利质量差
   - 持续<0：高度警惕

2. **销售商品收到的现金分析**
   ```
   现金收入比 = 销售商品收到的现金 / 营业收入
   ```
   - 应≥1（含税）
   - 考虑增值税因素，正常在1.13-1.15之间
   - <1：应收账款增加或收入造假

3. **购买商品支付的现金分析**
   - 与营业成本、存货变动匹配
   - 异常需检查原因

4. **连续3年经营现金流**
   - 持续为正：优秀
   - 持续为负：警惕
   - 波动大：不稳定

#### 异常线索（非违规）
- 经营现金流持续为负
- 现金流含金量<0.5
- 现金收入比<90%
- 净利润为正但现金流为负

**正常解释：**
- 快速扩张期
- 账期延长
- 预付账款增加
- 存货备货

#### 已证实违规案例
**康得新案例**
- 虚增利润119亿元
- 经营现金流长期为负
- 现金流含金量<0
- 出处：第312-314页

#### 出处
- 第4章 现金流量表，第93-115页
- 第11章 财务舞弊识别，第312-314页

## 四、股票估值方法

### 4.1 市盈率估值法（PE）

#### 概念
市盈率 = 股价 / 每股收益（EPS）

#### 适用条件
- 盈利稳定的成熟企业
- 不适用于亏损企业
- 不适用于周期性很强的企业

#### 估值步骤
1. **确定合理PE范围**
   - 行业平均PE
   - 公司历史PE
   - 同类公司PE

2. **预测未来每股收益**
   - 基于过去3-5年增长率
   - 考虑行业前景
   - 保守估计

3. **计算合理股价**
   ```
   合理股价 = 预测EPS × 合理PE
   ```

4. **安全边际**
   - 留30%-40%安全边际
   - 买入价 = 合理股价 × 60%-70%

#### 适用行业
- 消费品（白酒、食品）
- 医药
- 零售
- 银行（更常用PB）

#### 不适用情况
- 周期股（钢铁、煤炭）
- 亏损企业
- 科技成长股（PE过高）

#### 案例
**贵州茅台估值（2020年）**
- 当年EPS预计：43元
- 行业平均PE：30-40倍
- 合理估值：43 × 35 = 1505元
- 安全买入价：1505 × 0.7 = 1054元
- 出处：第267-270页

---

### 4.2 市净率估值法（PB）

#### 概念
市净率 = 股价 / 每股净资产

#### 适用条件
- 重资产行业
- 净资产相对稳定的企业
- 特别适合银行、地产

#### 估值步骤
1. **确定合理PB**
   - 行业平均PB
   - 公司历史PB
   - ROE水平决定PB

2. **PB与ROE关系**
   ```
   合理PB = ROE / 市场要求回报率
   ```
   - ROE 15%，要求回报10%，合理PB=1.5

3. **计算合理股价**
   ```
   合理股价 = 每股净资产 × 合理PB
   ```

#### 适用行业
- 银行
- 保险
- 房地产
- 钢铁、有色

#### 案例
**招商银行估值**
- 每股净资产：40元
- ROE：15%
- 合理PB：1.5-2倍
- 合理股价：40 × 1.75 = 70元
- 出处：第270-273页

---

### 4.3 现金流折现法（DCF）

#### 概念
公司价值 = 未来现金流的现值总和

#### 适用条件
- 适用于所有企业
- 特别适合现金流稳定的企业
- 需要较强的预测能力

#### 估值步骤
1. **预测未来5-10年自由现金流**
   ```
   自由现金流 = 经营现金流 - 资本支出
   ```

2. **确定折现率（WACC）**
   - 一般使用8%-12%
   - 高风险企业用高折现率

3. **计算永续价值**
   ```
   永续价值 = 第N年现金流 × (1 + 永续增长率) / (折现率 - 永续增长率)
   ```

4. **计算现值总和**

#### 优缺点
**优点：**
- 理论上最准确
- 适用范围广

**缺点：**
- 预测难度大
- 对假设敏感

#### 出处
- 第10章 股票估值，第273-282页

## 五、财务舞弊识别

### 5.1 财务舞弊常见手段

#### 1. 虚增收入
**手段：**
- 虚构交易
- 提前确认收入
- 关联方交易

**识别方法：**
- 现金收入比<90%
- 应收账款/营收>40%
- 应收账款增速>营收增速
- 四季度收入占比>50%

#### 2. 虚减成本
**手段：**
- 费用资本化
- 成本挂账存货
- 折旧摊销不足

**识别方法：**
- 毛利率异常高于行业
- 存货异常增加
- 固定资产占比异常高

#### 3. 虚增资产
**手段：**
- 虚增货币资金
- 虚增存货
- 虚增应收账款

**识别方法：**
- 大额资产但利息收入很低
- 资产与经营规模不匹配
- 资产周转率异常低

#### 4. 隐瞒负债
**手段：**
- 表外融资
- 或有负债不披露
- 关联方占款

**识别方法：**
- 担保金额异常大
- 其他应收款异常高
- 经营现金流与利润不匹配

---

### 5.2 财务舞弊识别检查清单

#### 资产负债表检查
□ 货币资金与利息收入是否匹配？
□ 货币资金与有息负债是否合理？
□ 应收账款增长是否超过营收增长？
□ 应收账款周转天数是否异常延长？
□ 存货周转率是否显著下降？
□ 固定资产占比是否异常高？

#### 利润表检查
□ 毛利率是否异常高于同行？
□ 费用率是否异常低于同行？
□ 四季度收入占比是否过高？
□ 营业外收入是否频繁出现？
□ 关联交易占比是否过高？

#### 现金流量表检查
□ 经营现金流是否持续为负？
□ 现金流含金量是否<0.8？
□ 现金收入比是否<90%？
□ 投资活动现金流是否异常？
