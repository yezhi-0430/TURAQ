**版本信息：**

## 核心框架：七大财务诡计

### 诡计1：过早或虚构地确认收入

#### 1.1 在交付产品或服务前确认收入

**概念**
企业在实际交付产品或完成服务前就记录收入。

**适用条件**
所有行业，特别是软件、工程、订阅服务行业

**检查步骤**
1. 检查收入确认政策（年报附注）
2. 对比同行业收入确认时点
3. 查看预收账款变动
4. 检查退货率和退货准备

**异常线索（非违规）**
- 预收账款大幅减少，同时收入大增
- 收入确认时点早于同行
- 第四季度收入占比异常高
- 退货率突然下降

**正常解释：**
- 客户提前验收
- 合同条款变化
- 季节性因素

**已证实违规案例**

**案例1：Sunbeam（阳光）公司**
- 手法：在客户实际需要前提前发货，虚假确认收入
- 特征：应收账款激增，退货准备不足
- 检测方法：应收账款周转天数从45天延长至65天
- 出处：第1章，第15-18页

**案例2：MicroStrategy**
- 手法：在软件交付和实施前确认收入
- 特征：递延收入（预收账款）占比异常低
- 出处：第1章，第22-24页

#### 出处
- 第1章 诡计1：过早或虚构地确认收入，第3-45页

---

#### 1.2 在最终不确定性依然存在时确认收入

**概念**
在销售结果仍不确定（如客户付款能力、退货可能性）时确认收入。

**适用条件**
所有信用销售企业

**检查步骤**
1. **检查应收账款质量**
   - 账龄超过1年的应收占比
   - 坏账准备计提比例
   
2. **检查客户信用状况**
   - 关联方占比
   - 单一客户占比

3. **检查退货和折让**
   - 销售退回占收入比例
   - 折让和折扣比例

4. **检查收入确认条件**
   - 是否存在重大不确定性
   - 回款条件是否苛刻

**异常线索（非违规）**
- 应收账款账龄结构恶化
- 坏账准备计提比例低于同行
- 大额关联方应收长期挂账
- 退货和折让比例异常高

**正常解释：**
- 行业账期延长
- 拓展新客户给予更长账期
- 客户暂时困难但基本面良好

**已证实违规案例**

**案例：Xerox（施乐）**
- 手法：在客户付款高度不确定时确认收入
- 特征：长期应收占比高，坏账准备不足
- 检测方法：坏账准备/应收账款 < 行业水平50%
- 出处：第1章，第28-31页

#### 出处
- 第1章，第25-35页

---

#### 1.3 记录缺乏经济实质的收入

**概念**
记录没有真实交易支撑的收入，如关联方交易、往来交易等。

**适用条件**
所有企业

**检查步骤**
1. **检查关联交易**
   - 关联方销售占比
   - 关联方应收账款占比
   - 交易价格公允性

2. **检查往来交易（圆桌交易）**
   - 是否存在互相购买
   - 交易是否有商业实质

3. **检查渠道销售**
   - 经销商囤货情况
   - 终端销售数据

4. **检查销售与采购匹配**
   - 销售增长但采购不增长
   - 销售增长但生产人员不增加

**异常线索（非违规）**
- 关联方销售占比>30%
- 关联方应收长期不回款
- 存在循环交易迹象
- 销售增长但成本不增

**正常解释：**
- 集团内部交易
- 产业链协同
- 轻资产模式（代工）

**已证实违规案例**

**案例1：Enron（安然）**
- 手法：通过关联SPE（特殊目的实体）虚增收入
- 特征：关联交易占比高，交易复杂难懂
- 出处：第1章，第35-38页

**案例2：A股蓝田股份**
- 手法：虚构销售合同，关联方配合
- 特征：应收账款不回款，关联方占比高
- 出处：第1章，第40-42页（中国版增补）

#### 出处
- 第1章，第35-45页

### 诡计2：记录虚假收入

#### 2.1 记录完全虚构的销售

**概念**
记录根本不存在的销售交易。

**适用条件**
所有企业

**检查步骤**
1. **现金流验证**
   ```
   现金收入比 = 销售商品收到的现金 / 营业收入（含税）
   ```
   - 正常应≥100%（考虑增值税1.13或1.09）
   - <90%高度警惕

2. **应收账款验证**
   - 应收账款增速 vs 营收增速
   - 应收账款绝对额是否合理

3. **存货验证**
   - 存货减少量 vs 营业成本
   - 存货周转率是否合理

4. **第三方验证**
   - 客户函证
   - 物流记录
   - 银行流水

**异常线索（非违规）**
- 现金收入比<80%
- 应收账款增速远超营收
- 收入大增但现金流为负
- 存货不减反增

**正常解释：**
- 赊销比例增加
- 账期延长
- 季节性备货

**已证实违规案例**

**案例1：万福生科（中国A股）**
- 手法：伪造销售合同、发货单、银行回单
- 特征：
  - 现金收入比<50%
  - 应收账款/营收>60%
  - 经营现金流持续为负
- 检测指标：
  ```
  现金收入比 = 48%（正常应>110%）
  应收账款周转天数 = 220天（同行60天）
  ```
- 出处：第2章，第52-55页

**案例2：绿大地（中国A股）**
- 手法：虚构种植面积和产量
- 特征：存货周转率异常低，毛利率异常高
- 出处：第2章，第58-60页

#### 出处
- 第2章 诡计2：记录虚假收入，第47-68页

### 诡计3：通过一次性或不可持续活动提升收入

#### 3.1 通过一次性事件提升收入

**概念**
将非经常性收入计入营业收入或主营业务收入。

**适用条件**
所有企业

**检查步骤**
1. **检查营业外收入**
   - 政府补助占利润比例
   - 资产处置收益占比
   - 投资收益占比

2. **检查其他业务收入**
   - 是否为主营业务
   - 是否可持续

3. **检查收入结构变化**
   - 主营业务收入占比
   - 新增收入来源

4. **检查利润来源**
   ```
   核心利润 = 净利润 - 投资收益 - 政府补助 - 资产处置收益
   ```

**异常线索（非违规）**
- 政府补助占净利润>20%
- 投资收益占净利润>30%
- 资产处置收益突然增加
- 营业外收入占比高

**正常解释：**
- 政策性补贴
- 正常资产更新
- 股权投资收益

**已证实违规案例**

**案例：*ST华泽**
- 手法：通过关联方资产处置虚增利润
- 特征：营业外收入占净利润>80%
- 出处：第3章，第75-78页

#### 出处
- 第3章 诡计3：通过一次性活动提升收入，第69-92页

### 诡计4：将当期费用推移至后期

#### 4.1 不当资本化正常运营费用

**概念**
将应该计入当期费用的支出资本化，分期摊销。

**适用条件**
所有企业，特别是研发、软件、房地产企业

**检查步骤**
1. **检查资本化政策**
   - 研发费用资本化比例
   - 利息资本化金额
   - 软件开发资本化政策

2. **对比同行**
   - 资本化率对比
   - 费用率对比

3. **检查资本化趋势**
   - 资本化比例是否逐年提高
   - 与业务发展是否匹配

4. **检查无形资产和开发支出**
   - 无形资产增长是否合理
   - 开发支出占比

**异常线索（非违规）**
- 研发费用资本化率>80%（同行<50%）
- 管理费用率异常低
- 无形资产占比异常高
- 资本化比例逐年提高

**正常解释：**
- 进入产业化阶段
- 研发项目成功率高
- 会计政策调整

**已证实违规案例**

**案例1：WorldCom（世通）**
- 手法：将线路成本资本化为固定资产
- 金额：38亿美元
- 特征：
  - 固定资产异常增长
  - 折旧费用不合理
  - 资本支出与收入不匹配
- 检测方法：对比同行资本支出/收入比
- 出处：第4章，第98-102页

**案例2：乐视网（中国A股）**
- 手法：将内容采购成本资本化为版权资产
- 特征：
  - 无形资产占比>60%
  - 内容成本资本化率>90%（同行<50%）
  - 摊销期过长
- 出处：第4章，第108-110页

#### 出处
- 第4章 诡计4：将当期费用推移至后期，第93-128页

---

#### 4.2 低估所需的准备金或应计负债

**概念**
坏账准备、存货跌价准备等计提不足。

**适用条件**
所有企业

**检查步骤**
1. **坏账准备检查**
   ```
   坏账准备率 = 坏账准备 / 应收账款
   ```
   - 对比同行业水平
   - 对比历史实际坏账率

2. **存货跌价准备检查**
   - 对比同行计提比例
   - 检查存货账龄
   - 关注滞销产品

3. **其他准备检查**
   - 预计负债是否充分
   - 质保金是否足够
   - 诉讼损失准备

4. **账龄分析**
   - 1年以上应收占比
   - 2年以上存货占比

**异常线索（非违规）**
- 坏账准备率低于同行50%
- 存货跌价准备为0
- 长期应收不计提坏账
- 账龄3年以上仍不计提

**正常解释：**
- 客户质量好
- 存货周转快
- 历史坏账率低

**已证实违规案例**

**案例：Lucent（朗讯）**
- 手法：低估客户还款风险，坏账准备不足
- 特征：
  - 坏账准备率1%（同行5-8%）
  - 应收账款激增
  - 后期大额核销
- 出处：第4章，第115-118页

#### 出处
- 第4章，第110-128页

### 诡计5：隐藏负债或有息负债

#### 5.1 表外融资

**概念**
通过特殊工具（SPE、信托等）进行融资，不在资产负债表体现。

**适用条件**
所有企业

**检查步骤**
1. **检查合并范围**
   - 子公司、SPV是否全部纳入合并
   - 关注未纳入合并的关联方

2. **检查担保和承诺**
   - 对外担保金额
   - 担保对象（特别是关联方）
   - 或有负债

3. **检查其他应收款**
   - 大额其他应收款用途
   - 是否为变相借款

4. **检查经营租赁**
   - 大额长期租赁
   - 租赁期限和金额

**异常线索（非违规）**
- 对外担保金额>净资产50%
- 其他应收款异常大
- 关联方资金往来频繁
- 未纳入合并的重要SPV

**正常解释：**
- 正常业务担保
- 员工借款
- 押金保证金

**已证实违规案例**

**案例：Enron（安然）**
- 手法：通过SPE隐藏债务
- 特征：
  - 资产负债率低（40%）但实际高杠杆
  - 大量未并表SPE
  - 对SPE提供担保和支持
- 出处：第5章，第135-142页

#### 出处
- 第5章 诡计5：隐藏负债，第129-158页

### 诡计6：将当期收入推移至后期

#### 6.1 不恰当地将收入推迟到未来期间

**概念**
企业为了平滑利润，将当期收入推迟确认。

**适用条件**
所有企业

**检查步骤**
1. **检查预收账款**
   - 预收账款占比是否异常高
   - 预收账款增长是否合理

2. **检查递延收入**
   - 递延收入确认政策
   - 递延收入转收入速度

3. **检查收入趋势**
   - 连续多年收入平稳增长（如每年15%）
   - 波动极小

4. **检查季度收入分布**
   - 是否过于均匀
   - 是否缺乏季节性

**异常线索（非违规）**
- 预收账款异常高
- 收入异常平稳
- 递延收入长期挂账

**正常解释：**
- 预售模式（如房地产）
- 订阅模式（如SaaS）
- 业务确实稳定

#### 出处
- 第6章 诡计6：推移收入至后期，第159-174页

### 诡计7：将后期费用提前或将当期收入列为前期

#### 7.1 将未来费用记为特殊费用

**概念**
通过计提大额"一次性费用"，将未来费用提前。

**适用条件**
所有企业

**检查步骤**
1. **检查资产减值**
   - 减值金额是否异常大
   - 减值时点选择

2. **检查重组费用**
   - 重组费用是否包含未来费用
   - 重组准备是否合理

3. **检查后续期间费用**
   - 计提大额费用后，后续费用率是否下降

**异常线索（非违规）**
- 一次性计提巨额减值
- 重组费用异常大
- 后续期间费用率异常低

#### 出处
- 第7章 诡计7：费用时点操纵，第175-192页

## 现金流诡计

### 现金流诡计1：从经营活动中挤榨现金

**概念**
通过操纵营运资本，短期改善经营现金流。

**检查步骤**
1. **检查应收账款变化**
   - 应收账款减少（收紧信用或出售应收）
   - 是否可持续

2. **检查存货变化**
   - 存货大幅减少
   - 是否为清仓处理

3. **检查应付账款变化**
   - 应付账款大幅增加
   - 是否延迟支付供应商

4. **检查预收账款**
   - 预收大幅增加
   - 是否为短期行为

**异常线索（非违规）**
- 经营现金流突然大增，但由营运资本改善
- 应付账款周转天数突然延长
- 存货清仓式下降

**正常解释：**
- 改善运营效率
- 行业账期变化
- 季节性因素

#### 出处
- 第8章 现金流诡计1，第195-212页

---

### 现金流诡计2：将融资活动现金流入记为经营流入

**概念**
将借款、股东投资等计入经营活动现金流。

**检查步骤**
1. **检查现金流量表结构**
   - 销售商品收到的现金是否异常高
   - 筹资活动现金流入是否异常低

2. **检查资产证券化**
   - 应收账款证券化
   - 是否记为销售收入

3. **检查供应链金融**
   - 保理业务
   - 记账科目

**异常线索（非违规）**
- 销售收现>营收130%（考虑增值税后）
- 应收账款减少但无法解释
- 融资活动现金流异常低

#### 出处
- 第9章 现金流诡计2，第213-228页

---

### 现金流诡计3：将经营现金流出记为投资流出

**概念**
将经营性支出资本化，计入投资活动。

**检查步骤**
1. **检查资本支出**
   - 资本支出/营收比
   - 对比同行

2. **检查固定资产**
   - 固定资产增速
   - 与收入增速匹配

3. **检查折旧**
   - 折旧政策
   - 折旧率

**异常线索（非违规）**
- 资本支出异常高
- 经营现金流改善但资本支出暴增

#### 出处
- 第10章 现金流诡计3，第229-242页

## 关键指标预警体系

### 收入质量指标

| 指标 | 计算方法 | 警戒线 | 说明 |
|------|----------|--------|------|
| 现金收入比 | 销售商品收到现金/营业收入(含税) | <100% | 考虑增值税应≥110% |
| 应收账款/营收 | 应收账款/营业收入 | >40% | 行业差异大 |
| 应收增速/营收增速 | - | >1.5倍 | 持续2年以上警惕 |
| 第四季度占比 | Q4收入/全年收入 | >40% | 非季节性行业 |

## 使用建议

**1. 综合判断原则**
- 单一异常指标≠财务造假
- 多个异常同时出现，警惕度提高
- 3个以上红色预警，高度警惕

**2. 趋势分析原则**
- 关注连续3年以上趋势
- 突然变化比绝对值更重要

**3. 行业对比原则**
- 所有指标必须与同行对比
- 不同行业标准差异极大

**4. 证据链原则**
- 异常线索→深入调查→寻找证据
- 不轻易下结论
