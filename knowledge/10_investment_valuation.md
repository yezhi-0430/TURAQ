## 第一部分：估值基础

### 1.1 三种估值方法

#### 概念
企业估值的三大类方法：
1. 折现现金流估值（DCF）
2. 相对估值（可比公司法）
3. 期权定价法（实物期权）

#### 适用条件

**DCF法适用：**
- 现金流可预测的成熟企业
- 有稳定商业模式
- 财务数据可靠

**相对估值适用：**
- 有可比公司
- 行业成熟
- 快速估值

**期权定价适用：**
- 早期科技公司
- 资源类公司
- 有战略期权价值的企业

#### 出处
- 第1章 估值方法概述，第1-25页

## 第二部分：折现现金流估值（DCF）

### 2.1 股权自由现金流模型（FCFE）

#### 概念
股权自由现金流 = 归属股东的可分配现金流

#### 计算公式
```
FCFE = 净利润 
     + 折旧摊销
     - 资本支出
     - 营运资本增加
     + 新增借款
     - 偿还借款
```

#### 适用条件
- 适用于所有公司
- 特别适合有稳定资本结构的公司

#### 估值步骤

**第一步：预测未来FCFE**

**高增长期（1-5年）：**
- 详细预测每年FCFE
- 基于历史增长率
- 考虑行业前景

**稳定增长期（5年后）：**
- 假设永续增长
- 增长率通常2%-4%（接近GDP增长）

**第二步：确定股权成本（折现率）**

**CAPM模型：**
```
股权成本 = 无风险利率 + β × 市场风险溢价

中国市场参数：
- 无风险利率：3%-4%（10年期国债）
- 市场风险溢价：8%-10%
- β系数：查询或回归计算
```

**第三步：折现计算**

```
企业价值 = Σ[FCFE_t / (1+r)^t] + 终值 / (1+r)^n

其中：
终值 = FCFE_n+1 / (r - g)
r = 股权成本
g = 永续增长率
```

**第四步：敏感性分析**

| 永续增长率 | 折现率9% | 折现率10% | 折现率11% |
|------------|----------|-----------|-----------|
| 2% | 100 | 90 | 82 |
| 3% | 120 | 105 | 93 |
| 4% | 150 | 125 | 106 |

#### A股实战案例

**案例：贵州茅台估值（2020年）**

**参数设定：**
- 2019年净利润：412亿
- 资本支出：40亿
- 营运资本变动：-50亿（预收增加）
- 无负债企业
- FCFE ≈ 422亿

**增长假设：**
- 1-5年增长率：15%
- 6-10年增长率：10%
- 永续增长率：3%

**折现率：**
- 无风险利率：3.5%
- β = 0.8
- 市场风险溢价：9%
- 股权成本 = 3.5% + 0.8 × 9% = 10.7%

**计算结果：**
- 10年现金流现值：5,200亿
- 永续价值现值：7,800亿
- 企业总价值：13,000亿
- 每股价值：约1,040元

**敏感性分析：**
- 乐观情形（增长率+2%）：1,300元
- 基准情形：1,040元
- 悲观情形（增长率-2%）：800元

#### 出处
- 第5章 股权自由现金流估值，第125-165页

### 2.2 企业自由现金流模型（FCFF）

#### 概念
企业自由现金流 = 所有资金提供者可分配的现金流

#### 计算公式
```
FCFF = EBIT × (1 - 税率)
     + 折旧摊销
     - 资本支出
     - 营运资本增加

或：
FCFF = FCFE + 利息费用 × (1 - 税率) + 本金偿还 - 新增借款
```

#### 适用条件
- 适合有债务的公司
- 资本结构变化的公司
- 并购估值

#### 估值步骤

**第一步：计算WACC（加权平均资本成本）**

```
WACC = (股权价值/企业价值) × 股权成本 
     + (债务价值/企业价值) × 债务成本 × (1 - 税率)

中国企业典型WACC：8%-12%
```

**第二步：预测FCFF**
- 预测EBIT
- 预测资本支出
- 预测营运资本变动

**第三步：折现**
```
企业价值 = Σ[FCFF_t / (1+WACC)^t] + 终值 / (1+WACC)^n

股权价值 = 企业价值 - 债务价值 + 现金
```

#### 案例：万科估值（含负债）

**参数：**
- 2019年EBIT：600亿
- 税率：25%
- 资本支出：200亿
- 有息负债：3,000亿
- 债务成本：5%
- 股权成本：11%
- WACC = 8%

**计算：**
- FCFF = 600 × 0.75 + 折旧150 - 资本支出200 - 营运资本100 = 300亿
- 10年现金流现值：2,500亿
- 永续价值现值：5,000亿
- 企业价值：7,500亿
- 股权价值 = 7,500 - 3,000 + 500（现金）= 5,000亿

#### 出处
- 第6章 企业自由现金流估值，第166-208页

### 2.3 股利折现模型（DDM）

#### 概念
股权价值 = 未来股利的现值总和

#### 基本模型

**戈登增长模型（永续增长）：**
```
股权价值 = 下期股利 / (股权成本 - 股利增长率)

P = D1 / (r - g)
```

#### 适用条件
- 成熟企业
- 稳定分红
- 股利增长率 < 股权成本

#### 两阶段模型

**高增长+稳定增长：**
```
第一阶段：详细预测每年股利
第二阶段：永续增长

价值 = Σ[D_t / (1+r)^t] + [D_n+1 / (r-g)] / (1+r)^n
```

#### A股实战：高分红公司估值

**案例：长江电力**
- 年股利：约1元/股
- 股利增长率：3%
- 股权成本：8%
- 股价 = 1 / (0.08 - 0.03) = 20元

#### 出处
- 第7章 股利折现模型，第209-235页

## 第三部分：相对估值法

### 3.1 市盈率估值（PE）

#### 概念
```
PE = 股价 / 每股收益（EPS）
或
PE = 市值 / 净利润
```

#### 合理PE的决定因素

**理论公式（来自DDM）：**
```
PE = (1 - b) × (1 + g) / (r - g)

其中：
b = 留存率
g = 增长率
r = 股权成本
```

**推导结论：**
- PE与增长率正相关
- PE与风险（r）负相关
- PE与分红率正相关

#### PE估值步骤

**第一步：选择可比公司**
- 同行业
- 相似规模
- 相似增长率
- 相似ROE

**第二步：计算行业PE**
- 行业平均PE
- 行业中位数PE
- 剔除极端值

**第三步：调整PE**
```
目标公司合理PE = 行业PE × (1 + 调整系数)

调整系数考虑：
- 增长率差异
- ROE差异  
- 风险差异
```

**第四步：计算目标价**
```
目标价 = 预测EPS × 合理PE
```

#### PE估值的误区

**误区1：只看静态PE**
- 应该看动态PE（预测PE）
- TTM PE（最近12个月）

**误区2：忽略增长**
- 应该用PEG调整
- PEG = PE / 增长率
- PEG < 1为低估

**误区3：忽略ROE**
- 高ROE企业应享受高PE
- 低ROE企业应折价

#### A股行业PE参考（2020年）

| 行业 | PE范围 | 典型公司 |
|------|--------|----------|
| 白酒 | 30-50 | 茅台50倍，五粮液35倍 |
| 银行 | 5-10 | 招商银行10倍，四大行6倍 |
| 地产 | 8-15 | 万科12倍，融创10倍 |
| 医药 | 25-40 | 恒瑞医药50倍，云南白药30倍 |
| 家电 | 10-20 | 格力15倍，美的18倍 |
| 消费 | 20-35 | 海天味业40倍，伊利20倍 |

#### 出处
- 第8章 市盈率估值，第236-278页

### 3.2 市净率估值（PB）

#### 概念
```
PB = 股价 / 每股净资产
或
PB = 市值 / 净资产
```

#### 合理PB的决定因素

**理论公式：**
```
PB = ROE × (1 - b) × (1 + g) / (r - g)

简化：
PB ≈ ROE / (r - g)
```

**推导结论：**
- PB与ROE高度正相关
- 高ROE企业应享受高PB
- 低ROE企业PB接近1或低于1

#### PB估值步骤

**第一步：计算ROE**
```
ROE = 净利润 / 平均净资产

要求：
- 连续3年ROE > 15%为优秀
- ROE稳定性
```

**第二步：确定合理PB**
```
经验公式（中国市场）：
ROE 20%+ → PB 3-5倍
ROE 15%-20% → PB 2-3倍
ROE 10%-15% → PB 1.5-2倍
ROE < 10% → PB < 1.5倍
```

**第三步：计算目标价**
```
目标价 = 每股净资产 × 合理PB
```

#### PB估值的适用行业

**最适合：**
- 银行：重资产，ROE稳定
- 保险：资产价值重要
- 地产：资产占比大

**较适合：**
- 制造业：有形资产多
- 钢铁、有色

**不适合：**
- 轻资产公司：互联网、咨询
- 亏损企业：净资产为负

#### 案例：招商银行PB估值

**财务数据：**
- ROE：16%
- 每股净资产：30元
- 行业平均PB：0.9倍
- 招商银行ROE显著高于同业

**估值：**
- 合理PB = 行业PB × (招商ROE / 行业ROE)
- 合理PB = 0.9 × (16% / 11%) = 1.3倍
- 目标价 = 30 × 1.3 = 39元

#### 出处
- 第9章 市净率估值，第279-310页

### 3.3 市销率估值（PS）

#### 概念
```
PS = 股价 / 每股营收
或
PS = 市值 / 营业收入
```

#### 适用条件
- 亏损企业（无PE可用）
- 早期成长企业
- 周期性企业（利润波动大）

#### 合理PS的决定因素

**理论公式：**
```
PS = 净利率 × PE

或：
PS = 净利率 × (1 - b) × (1 + g) / (r - g)
```

**推导结论：**
- PS与净利率正相关
- 高净利率企业应享受高PS

#### A股行业PS参考

| 行业 | PS范围 | 净利率 |
|------|--------|--------|
| 白酒 | 8-15倍 | 40%-50% |
| 医药 | 3-8倍 | 10%-20% |
| 零售 | 0.5-1.5倍 | 2%-5% |
| 互联网 | 5-15倍 | 20%-30% |

#### 出处
- 第10章 市销率估值，第311-330页

### 3.4 EV/EBITDA估值

#### 概念
```
EV = 市值 + 净负债（有息负债 - 现金）
EBITDA = EBIT + 折旧摊销

EV/EBITDA = 企业价值 / 息税折旧摊销前利润
```

#### 适用条件
- 有负债的公司
- 资本结构不同的公司对比
- 并购估值

#### 优势
- 剔除资本结构影响
- 剔除折旧政策影响
- 国际通用

#### A股典型倍数

| 行业 | EV/EBITDA |
|------|-----------|
| 消费 | 15-25倍 |
| 医药 | 20-30倍 |
| 制造 | 8-15倍 |
| 周期 | 5-10倍 |

#### 出处
- 第11章 EV/EBITDA估值，第331-355页

## 第四部分：估值中的特殊问题

### 4.1 周期性公司估值

#### 挑战
- 利润波动大
- PE、PB失真
- 预测困难

#### 解决方法

**1. 使用周期调整PE**
```
周期调整PE = 当前股价 / 周期平均EPS

周期平均EPS = 过去10年平均净利润 / 当前股本
```

**2. 使用PB估值**
- 周期底部：PB接近1甚至破净
- 周期顶部：PB 2-3倍

**3. 使用重置成本法**
- 计算资产重置成本
- 对比市值

#### 反向投资策略
- 周期底部（PE很高时）买入
- 周期顶部（PE很低时）卖出

#### 出处
- 第14章 周期性公司估值，第405-430页

---

### 4.2 高成长公司估值

#### 挑战
- 当前无盈利或盈利很少
- PE极高或无意义
- 不确定性大

#### 解决方法

**1. 使用PS估值**
- 对比同行业成熟公司PS
- 预测达到稳定期的净利率
- 反推合理PS

**2. 使用PEG**
- 高成长公司PE高属正常
- PEG = PE / 未来3年增长率
- PEG < 1为低估

**3. 分阶段DCF**
- 详细预测达到成熟期的路径
- 每年现金流预测
- 终值计算关键

#### 风险调整
- 使用更高折现率（12%-15%）
- 使用概率加权（成功率×价值）
- 敏感性分析

#### 案例：新能源车企估值

**参数：**
- 当前亏损
- 预计5年后盈利100亿
- 10年后稳定在200亿
- 高风险，折现率15%

**方法：**
- 分年预测10年现金流
- 折现至今
- 考虑成功概率50%
- 价值 = DCF × 成功概率

#### 出处
- 第15章 高成长公司估值，第431-465页

### 4.3 金融企业估值

#### 银行估值特点
- 资产负债表是主表
- 债务是原材料，不是负债
- 不适用FCFF

#### 银行估值方法

**方法1：股利折现**
```
银行价值 = Σ[未来股利现值]

银行分红率通常30%-50%
```

**方法2：PB估值**
```
合理PB = ROE / (股权成本 - 增长率)

优秀银行（ROE>15%）：PB 1.5-2倍
普通银行（ROE 10%-15%）：PB 0.8-1.2倍
```

**方法3：超额收益模型**
```
银行价值 = 净资产 + 未来超额收益现值

超额收益 = (ROE - 股权成本) × 净资产
```

#### 案例：招商银行vs工商银行

| 指标 | 招商银行 | 工商银行 |
|------|----------|----------|
| ROE | 16% | 12% |
| PB | 1.5倍 | 0.7倍 |
| 合理性 | 合理 | 合理 |

#### 保险公司估值

**方法1：内含价值（EV）**
```
公司价值 = 内含价值 + 新业务价值

PEV = 市值 / 内含价值
优秀保险公司PEV：1.5-2倍
```

**方法2：P/NBV**
```
P/NBV = 市值 / 新业务价值

优秀保险公司：15-25倍
```

#### 出处
- 第16章 金融企业估值，第466-510页

## 第五部分：估值实战技巧

### 5.1 敏感性分析

#### 概念
分析关键假设变化对估值的影响

#### 关键变量
1. 增长率
2. 折现率
3. 永续增长率
4. 利润率

#### 敏感性矩阵示例

**贵州茅台估值敏感性：**

| 折现率\增长率 | 10% | 12% | 15% |
|---------------|-----|-----|-----|
| 9% | 1,500 | 1,800 | 2,200 |
| 10% | 1,200 | 1,400 | 1,700 |
| 11% | 1,000 | 1,200 | 1,400 |

**解读：**
- 估值对增长率更敏感
- 合理估值区间：1,000-2,200元
- 安全边际：按最保守情况

#### 出处
- 第18章 敏感性分析，第545-565页

---

### 5.2 蒙特卡洛模拟

#### 概念
对不确定性参数进行概率分布模拟，得出估值分布

#### 步骤
1. 确定关键变量及其分布
2. 随机抽样10,000次
3. 每次计算估值
4. 统计估值分布

#### 结果解读
- 估值均值：期望价值
- 估值分位数：
  - 25%分位：悲观情形
  - 50%分位：基准情形
  - 75%分位：乐观情形

#### 出处
- 第19章 蒙特卡洛模拟，第566-590页
