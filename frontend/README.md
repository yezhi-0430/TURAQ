# TURAQ 前端

当前入口是 `frontend/index.html`，使用深色/金色 TURAQ 界面。保留首页水波动画、T 标志悬停效果、页面平滑切换、证券目录搜索、自选管理及真实分时/K 线图。

## 本地启动

在项目根目录配置后端数据库和其他必需设置。开发站点与 Cookie 必须匹配浏览器实际访问的地址：

```powershell
$env:SITE_BASE_URL = 'http://localhost:3000'
$env:AUTH_COOKIE_SECURE = 'false'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8888
```

另一个终端运行：

```powershell
cd frontend
npm install
npm run dev
```

打开 `http://localhost:3000`。所有活动页面脚本通过 `api.js` 请求同源 `/api/v1/…`；Vite 仅代理 `/api/` 路径到 8888，保留浏览器 Origin 供后端 CSRF 校验。`api.js` 文件本身不会被代理。不要通过直接打开 HTML 或不代理 API 的静态 HTTP 服务进行账号验收。

生产环境需 HTTPS 同源部署，保留 Secure Cookie 默认值；本地 `AUTH_COOKIE_SECURE=false` 仅用于本机 HTTP 开发。生产静态文件和 `/api/` 应由同一个站点提供。

## 账号和邮件

进入工作台前必须登录已验证、可用的账号。账号身份来自后端 HttpOnly 会话 Cookie，前端不存密码、会话令牌或自行声明用户权限。JSON 写入附带当前会话的 CSRF 令牌。

登录、邀请码注册、验证邮箱、重发验证邮件、找回和重置密码在同一个账号窗口完成。注册与重置统一接受 6–15 个 Unicode 字符；不会自动修剪或截断密码。邮件链接支持 `/#verify=…`、`/#reset=…`，页面读取后清除地址中的令牌。

`mail_configured=false` 时明确显示真实邮件服务尚未配置，注册、重发及找回入口不能提交。已有已验证账号仍可登录。请求受理并不代表用户已收到邮件；真实 SMTP 与实际送达验收完成之前不能开放外部注册内测。

服务器操作者可使用 `python -m app.auth.admin bootstrap-admin --email <自己的邮箱> --verified-email`，在本地终端交互输入密码。该命令要求操作者明确确认邮箱身份，不是公共注册入口。没有预置演示账号或默认密码。本轮前端测试只使用隔离的合成身份，不修改正式数据库；正式建表、旧分组归属和管理员维护由操作者显式执行。

点击退出即停止行情刷新、关闭详情/确认窗口、清除自选/聊天/图表缓存，并进入登录流程；即使网络中断或服务端退出失败，本机工作台也会立即清除，并显示“服务端退出结果未确认”，不宣称远程会话已撤销。当前标签页的 sessionStorage 仅保存退出意图标记（不含身份、密码或令牌），重新加载或查询会话也不会恢复旧账号；只有显式提交凭据并成功登录后才解除该标记。账号切换或私有请求返回 401 时也清除私有状态。旧账号的迟到响应不会进入新账号页面。429 显示后端 Retry-After 信息。

## 研究与操作确认

研究界面根据后端 `model_mode` 明确显示“模型调用已关闭”“隔离测试模型”或“Qwen 在线模型”，不把测试回答描述为真实模型结果。工具来源区分执行时间 `executed_at` 和本次返回数据的最新交易日 `latest_trade_date`；后者仅描述本次返回区间，不代表市场当前最新交易日。显示本地数据库/Python 计算、记录数以及未知上游/采集时间；未提供来源时不推定数据日期。

模型建议始终显示“建议，尚未执行”。点击“查看并确认”会读取本人的分组和成员，确认窗口显示具体分组、证券代码和移除影响。只有最后一次确认发送严格的 `ExecutionRequest`；取消、模型附加的 `confirmed` 字段和重复点击均不会触发额外写入。

后端成功响应之后才刷新本人自选和行情。拒绝或错误保留失败状态。连接中断/超时显示“结果待确认”，只读核对目标状态，不自动重复写入；股票缺失也不会被当作原请求执行成功的证明。

## 证券目录、自选和图表

全局搜索与自选搜索使用公共 `GET /api/v1/stocks/search?q=…` 目录响应；页面只通过安全文本节点显示名称、代码和市场。清空、离开页面或账号变化会取消/忽略迟到搜索结果。目录可能不完整，不宣称覆盖全部 A 股；添加股票时后端继续核对可信资料。目录查询不返回私人分组。

自选页面支持创建、重命名、删除分组，添加/移除股票及进入研究助手。所有保存操作仍由后端会话授权；其他用户分组返回 404。行情表的临时查询/移除只改变当前页面，数据库成员由自选管理维护。

行情保留腾讯财经公开源的真实时间和缺失状态，失联时保留旧数据并标记。报价约 10 秒、图表约 30 秒自动刷新，关闭/隐藏时暂停；主分时支持十字线、午休压缩和真实源记录，独立详情提供成交均价、成交量以及日/周/月 K 线与不复权/前复权/后复权选择。最新月 K 的日线汇总口径在界面说明。休市返回最近交易日，不生成虚构行情。

## 验证与构建

项目根目录：

```powershell
node --test tests/frontend/*.test.mjs
npm run build --prefix frontend
node tests/frontend/build-assets.test.mjs
```

行为测试包含匿名门禁、CSRF、密码边界/Unicode、退出/401 缓存清理、迟到响应、目录安全渲染、确认取消、重复点击、后端拒绝、超时只读核对、来源日期及现有图表/自选回归。代理测试启动独立 Vite 和合成 HTTP 服务，检查 `api.js` 实际可加载且 Origin 原样转发；不连接模型、SMTP 或数据库。构建检查确认目录代码进入产物、所有资源存在、活动脚本没有跨域 localhost URL。

浏览器桌面/手机、双账号及真实邮件/少量真实模型的验收需分别记录。Node/构建测试和隔离假模型不等于已上线或真实送达成功。

隔离浏览器验收建议使用独立后端 8891 和前端 3001：前端环境设 `API_PROXY_TARGET=http://127.0.0.1:8891`，后端站点基础地址使用 `http://localhost:3001`。沿用 `tests/auth/conftest.py` 的隔离 SQLite、依赖覆盖、关闭调度器和测试邮件注入方式；覆盖所有使用 `SessionLocal` 的模块，并注入确定性的假模型/行情/目录数据。只在此独立进程内创建合成账号和分组；测试邮件令牌仅在受控夹具中读取，不加公共返回令牌端点。关闭两个夹具进程并删除临时 SQLite 即可清理，不替换现有 8888 服务。
