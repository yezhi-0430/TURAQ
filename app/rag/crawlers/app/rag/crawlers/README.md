# TURAQ - AI财报风险分析工具

## 项目简介

TURAQ是一个基于RAG（检索增强生成）技术的智能财报分析工具。上传财报PDF，系统自动提取财务指标、识别财务风险、并结合专业知识库给出分析建议。

**核心价值：** 将6本专业书籍的知识体系化，30分钟完成专业分析师3小时的工作。

---

## 技术栈

- **后端框架：** FastAPI
- **向量数据库：** ChromaDB
- **嵌入模型：** BAAI/bge-small-zh-v1.5（中文优化）
- **PDF解析：** PyPDF2
- **异步处理：** asyncio + httpx
- **Python版本：** 3.11+

---

## 核心功能

### 1. PDF财报解析
- 自动提取资产负债表、利润表、现金流量表
- 识别12+个核心财务指标
- 计算5+个财务比率

### 2. AI风险识别
基于专业知识库的规则引擎，自动识别：
- 财务造假风险（应收账款异常、现金流含金量低）
- 偿债风险（资产负债率高、流动比率低）
- 运营风险（存货周转率低）

### 3. 知识库检索
- 152个专业知识文档块
- 涵盖6本专业书籍：
  - 《财务诡计》- 识别财务造假
  - 《手把手教你读财报》- A股实战
  - 《财报就像一本故事书》- 财报分析
  - 《投资估价》- 估值方法
  - 《投资最重要的事》- 投资理念
  - 《置身事内》- 政策分析

### 4. 案例对比
- 结合历史案例（康美药业、万福生科等）
- 提供风险预警和应对建议

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 启动系统
```bash
# 1. 初始化知识库（首次运行）
python scripts/init_knowledge.py

# 2. 测试PDF解析
python app/analysis/pdf_parser.py

# 3. 测试风险分析
python app/analysis/risk_analyzer.py
```

### 使用示例
```python
from app.analysis.pdf_parser import FinancialReportParser
from app.analysis.risk_analyzer import RiskAnalyzer

# 1. 解析财报
parser = FinancialReportParser()
result = parser.parse_report('path/to/annual_report.pdf')

# 2. 分析风险
analyzer = RiskAnalyzer()
risks = analyzer.analyze_risks(
    result['indicators'],
    result['ratios'],
    company_name='贵州茅台'
)

# 3. 生成报告
report = analyzer.generate_risk_report(risks, '贵州茅台')
print(f"综合评分: {report['score']} 分")
print(f"投资建议: {report['recommendation']}")
```

## 核心算法

### 风险识别规则

```python
# 规则1：应收账款风险
if 应收账款/营收 > 40%:
    风险等级 = HIGH
    历史案例 = ["万福生科", "保千里"]

# 规则2：现金流风险
if 经营现金流/净利润 < 0.8:
    风险等级 = HIGH
    历史案例 = ["康美药业"]

# 规则3：偿债风险
if 资产负债率 > 70%:
    风险等级 = HIGH

# ... 更多规则
```

### RAG检索流程
1. 用户查询 -> 文本嵌入
2. 向量相似度检索（ChromaDB）
3. 返回最相关的知识文档
4. 结合规则引擎生成分析

## 技术难点与解决方案

### 难点1：PDF格式不统一
**问题：** 不同公司财报PDF格式差异大，表格结构不一致

**解决：** 
- 使用正则表达式匹配关键指标
- 多种模式兼容（合并报表、母公司报表）
- 容错机制（部分指标缺失仍可分析）

### 难点2：中文语义理解
**问题：** 财务术语专业性强，通用模型效果差

**解决：** 
- 使用BAAI/bge-small-zh-v1.5（中文优化）
- 针对性训练数据（6本专业书）
- 结构化文档（概念-条件-步骤-案例）

### 难点3：知识库更新
**问题：** 新案例、新规则如何持续加入

**解决：** 
- 设计文档唯一ID机制
- 增量更新不重复
- 自动入库pipeline
